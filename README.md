# Superstore Sales & Profitability Analysis

An end-to-end data analytics project using Excel, PostgreSQL, SQL, and Power BI to analyze sales, profitability, customers, products, regions, and discounts.

## Tools Used

- Excel – Data cleaning and validation
- PostgreSQL – Data storage and SQL analysis
- Power BI – Dashboard and visualization

## Project Workflow

CSV Dataset → Excel Data Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard

## Analysis Performed

- Overall sales and profit analysis
- Category-wise sales and profitability
- Top-selling products
- Regional performance
- Monthly sales trends
- Sub-category profitability
- Segment-wise performance
- Discount and profit analysis
- Top customers by sales
- Shipping mode analysis

## Key Insights

- Identified loss-making sub-categories
- Analyzed the relationship between discount levels and profitability
- Identified high-value customers
- Compared sales and profitability across categories and regions

## Files

- `data.csv` – Superstore dataset
- `queries.sql` – PostgreSQL SQL analysis queries
- `superstore analysis.pbix` – Power BI dashboard

## Dashboard

The Power BI dashboard provides an interactive view of sales, profit, category performance, sub-category profitability, monthly sales trends, and regional performance.
